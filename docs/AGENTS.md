# docs

`decisions/REPORT.md` and `decisions/check.md` override `design/` and `research/`. If you are about to quote a sentence from an older file, check those two first. The banner at the top of a design or research file is the short version of the same rule.

## Gotchas

- Do not add `learnings.md` or any note that names another team, a handle, a repo, or a file path in someone else's tree.
- Do not "fix" a superseded file by restating the old claim in new words. Either leave the banner or correct the line the way `check.md` does.
- Paper numbers and vendor timings stay labelled as someone else's. They are not Sheldon measurements.
- Spikes are at `/spikes`, not under `docs/`.
- The product name is Sheldon. SynapseOS in the older files is a leftover.

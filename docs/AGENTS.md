# docs

[`facts.md`](facts.md), [`decisions/REPORT.md`](decisions/REPORT.md), and [`engine/papers.md`](engine/papers.md) override `design/` and `research/`. If you are about to quote a sentence from an older file, check those three first. The banner at the top of a design or research file is the short version of the same rule. `papers.md` is the one that retires the personalized-PageRank design row.

## Gotchas

- Do not add a note that names another team, a handle, a repo, or a file path in someone else's tree.
- Do not "fix" a superseded file by restating the old claim in new words. Either leave the banner or correct the line in `facts.md`.
- Do not copy a quote from `research/pains.md` into the README or any UI text until someone has opened that quote's link. The Reddit quotes were taken from an archive and have not been checked live.
- Paper numbers and vendor timings stay labelled as someone else's. They are not Sheldon measurements.
- Spikes are at `/spikes`, not under `docs/`.
- The product name is Sheldon. SynapseOS in the older files is a leftover.
